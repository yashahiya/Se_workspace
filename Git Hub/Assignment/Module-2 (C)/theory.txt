Q.4->Explain the basic structure of a C program, including headers, main function, comments, data types, and variables. Provide examples.
ANS->A C program has a simple and well-defined structure. It begins with header files (like #include <stdio.h>) which provide predefined functions. The main() function is the entry point where program execution starts.

Q.5->Write notes explaining each type of operator in C: arithmetic, relational, logical, assignment, increment/decrement, bitwise, and conditional operators.
ANS->Logical operators combine multiple conditions, and assignment operators assign values to variables. Increment and decrement operators increase or decrease a value by one. Bitwise operators work at the bit level, and the conditional (ternary) operator is a short form of the if-else statement used for decision making.

Q.6->Explain decision-making statements in C (if, else, nested if-else, switch). Provide examples of each.
ANS->Decision-making statements in C are used to control the flow of a program based on conditions. The if statement executes a block of code when a condition is true, while else runs when the condition is false.

Q.7->Compare and contrast while loops, for loops, and do-while loops. Explain the scenarios in which each loop is most appropriate.
ANS->A for loop is best when the number of iterations is fixed or known, as initialization, condition, and increment are written in one line. A do-while loop executes the loop body at least once because the condition is checked after execution, making it useful when the loop must run at least one time (such as menu-driven programs).
